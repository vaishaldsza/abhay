Architecture Module Specifications

Technical specifications, runtime isolation, and operational design rationale across the stack.

hearing Gnani Prisma
MULTILINGUAL STT / ASR
Operational Role:

Transcribes low-bandwidth 8 kHz carrier audio with regional dialect adaptation (Kannada, Hindi, Hinglish, Tulu) on live telephony buffers.

Why This Architecture:

Telephony-grade acoustic robustness without external cloud latency. Handles packet drop and background urban disaster ambient acoustics.

Sampling: 8 kHz PCM Dialect Adaptation
filter_alt Gnani Evon
INTENT & SLOT EXTRACTION
Operational Role:

Identifies structured data fields (first name only, landmark, headcount, stretcher needs, water level) from raw transcription streams.

Why This Architecture:

Parses conversational answers into strict schema inputs. Never hallucinates entities; triggers affirmative DTMF confirmation if confidence is <0.82.

Output: JSON Schema Strict Slot Mask
code_blocksStatus Engine
PYTHON BACKEND
Operational Role:

Evaluates priority triage matrices, scheduled redials, vehicle assignments, and queue state transitions in memory via Python backend.

Why This Architecture:

Critical life-safety states must never be handed to LLM hallucinations or probabilistic models. State mutations require hard database transactions.

State: Postgres ACIDNo AI Write-Access
security Honesty Guard
HARD RULE INTERCEPTOR
Operational Role:

Validates candidate TTS scripts against active dispatch tables before generation. Intercepts false assurances before audio synthesis.

Why This Architecture:

Absolute zero-tolerance for premature rescue promises. If a unit has not accepted, the synthesizer can only acknowledge manifest receipt.

Safety Rule: PASS/FAIL Zero False Pledges
volume_up Gnani Timbre
NEURAL MULTILINGUAL TTS
Operational Role:

Generates calm, clear localized audio broadcasts with native Indian accent cadence across Hindi, Kannada, and Indian English.

Why This Architecture:

High intelligibility over degraded cellular and landline connections. Eliminates robotic cadence to calm distressed citizens during emergency calls.

Synthesis: G.711 / μ-law Localized Cadence

Number Masking Protocol

Minimal PII Persistence

Transcripts store First Names Only (e.g., "Rajesh", "Amina"). Aadhaar numbers and surnames are excluded from operational manifests.
